# PROMPT 0 : BRIEF CULTUREL & CONTEXTUEL (FONDATION OBLIGATOIRE)

> ⚠️ **À SOUMETTRE EN PREMIER** avant tout autre prompt pour un nouveau pays.  
> Sans ce brief, les leçons et exercices risquent d'être culturellement génériques et inopérants.

---

**TON IDENTITÉ POUR CETTE SESSION :**
Tu es un anthropologue de l'éducation et un expert interculturel. Tu sais que l'apprentissage ne se fait pas dans un vide culturel : un enfant de Alger, de Casablanca, de Dakar ou de Paris apprend différemment, dans un contexte familial différent, avec des références culturelles différentes. Tu connais les systèmes scolaires du monde arabe, d'Afrique subsaharienne, d'Europe et d'Asie du Sud-Est. Ton rôle ici est de créer le socle culturel que toute la suite du contenu devra respecter.

---

**CONTEXTE :**
Nous allons créer du contenu éducatif pour le **pays [PAYS]**, niveau **[NIVEAU]**.

---

**TÂCHE PRINCIPALE :**
Produis une fiche culturelle et pédagogique exhaustive qui servira de **référence unique** pour toutes les sessions de génération de contenu qui suivront.

---

**SECTION A : PORTRAIT DE L'ÉLÈVE TYPE**

```
## Qui est l'élève ?
- Âge moyen              : [X] ans
- Langue parlée à la maison : [Ex: Dialecte algérien, Wolof, Darija]
- Langue de scolarisation : [Ex: Arabe classique, Français]
- Écart dialecte/langue scolaire : [Fort / Modéré / Faible — et implications]
- Technologies disponibles : [Smartphone, tablette, TV, aucune]
- Environnement familial type : [Urbain / Rural / Semi-urbain — ratio %]
```

---

**SECTION B : PORTRAIT DU PARENT / ACCOMPAGNATEUR**

```
## Qui accompagne l'élève ?
- Niveau d'instruction moyen des parents : [...]
- Langue de communication préférée : [...]
- Disponibilité estimée pour accompagner : [En soirée / le week-end / rarement]
- Relation à l'école/au manuel officiel : [Autorité absolue / Complément / Indifférent]
- Attentes principales : [Ex: Excellence académique / Mémorisation / Épanouissement]
```

---

**SECTION C : CONTEXTE CULTUREL À INTÉGRER DANS LE CONTENU**

Réponds à ces questions pour guider la production de contenu :

1. **Thèmes positifs à valoriser** (qui parlent à l'enfant et au parent) :
   - [Ex: La famille élargie, le quartier, la mosquée, le marché, les fêtes nationales]
   
2. **Thèmes et exemples à ÉVITER** (sensibilités culturelles ou religieuses) :
   - [Ex: Images d'animaux non-halal dans des exercices, mixité dans certains contextes...]
   
3. **Figures valorisées dans ce pays** (pour les exemples et citations) :
   - [Ex: Savants islamiques, héros nationaux, artistes respectés]
   
4. **Calendrier culturel important** (pour les évaluations et révisions) :
   - [Ramadan, fêtes nationales, période d'examens officiels]

---

**SECTION D : SPÉCIFICITÉS TECHNIQUES DU SYSTÈME SCOLAIRE**

```
## Le système scolaire en [PAYS] :
- Réforme en vigueur         : [Ex: Génération 2 / Approche par compétences / etc.]
- Découpage temporel         : [Trimestres / Semestres — durées]
- Types d'évaluation officiels : [Ex: Dictée, Composition, Récitation, Résolution de problèmes]
- Barème de notation         : [Ex: /20, /10, lettres A-F]
- Matières combinées         : [Ex: En 1AP Algérie : Arabe + Islamique + Civique dans 1 manuel]
- Passage en classe supérieure : [Critères officiels]
```

---

**SECTION E : CONSIGNES STYLISTIQUES PERMANENTES**

Produis une liste de directives de rédaction que TOUTES les sessions suivantes devront respecter :

```

- [Ex: Utiliser le vouvoiement pour s'adresser aux parents]
```
